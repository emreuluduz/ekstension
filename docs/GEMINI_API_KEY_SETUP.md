# 🔑 Google Gemini API Anahtarı Kurulum Rehberi

`ek$tension` eklentisi, Ekşi Sözlük başlıklarını ve uzun entry'leri **1-2 saniye içinde, bilgisayarınızı hiç kasmadan ve tamamen ücretsiz** özetlemek için Google'ın resmi **Gemini 1.5 Flash** modelini kullanır.

Google, AI Studio üzerinden **ayda yüz binlerce kelimeye kadar tamamen ücretsiz** API anahtarı sağlamaktadır.

---

## ⚡ 10 Saniyede Ücretsiz API Key Alma Adımları

1. **Google AI Studio'yu Açın:**  
   👉 [https://aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey) adresine gidin.

2. **Google Hesabınızla Giriş Yapın:**  
   Herhangi bir standart Gmail/Google hesabınızla oturum açın.

3. **API Anahtarı Oluşturun:**  
   Mavi **"Create API Key"** (veya *"Get API Key"*) butonuna tıklayın.

4. **Anahtarınızı Kopyalayın:**  
   Oluşturulan `AIzaSy...` ile başlayan anahtarı kopyalayın.

5. **Eklentiye Kaydedin:**  
   - Ekşi Sözlük'te **`[ ⚡ Başlığı Özetle ]`** butonuna bastığınızda açılan kutuya yapıştırıp **"Kaydet ve Özetle"** deyin,  
   - veya tarayıcınızın sağ üstündeki **ek$tension** simgesine tıklayıp **Ayarlar -> Google Gemini AI** alanına yapıştırıp **Kaydet**'e basın.

## ✨ Neden Gemini 1.5 Flash?

* ⚡ **Işık Hızında:** 50 sayfalık koca bir başlığı 1.5 saniyede analiz eder.
* 💻 **Sıfır Donma / Kasıntı:** İşlem Google'ın bulut sunucularında çalıştığı için bilgisayarınızın işlemcisi veya fanı hiç yorulmaz.
* 🧠 **1 Milyon Token Kapasitesi:** Başlıktaki yüzlerce entry'nin tamamını tek seferde baştan sona eksiksiz okuyup sentezler.
* 🆓 **%100 Ücretsiz:** Google AI Studio, bireysel kullanım için ücretsiz kota sunar.
